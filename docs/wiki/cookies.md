# 需要登录态的站点

这些站点不接受匿名抓取。**在站点「设置 → 站点登录态」里绑定一次**，
worker 领到对应任务时会自动带上，不用改服务器 `.env`。

| 站点 | 需要什么 | 从哪拿 | 不配置的后果 |
| --- | --- | --- | --- |
| **知乎** | 整条 Cookie（含 `z_c0`） | 登录知乎 → F12 → Network → 任意请求 → 复制 `Cookie` 整行 | 403 / 跳登录页 |
| **B 站（官方字幕）** | `SESSDATA` 的值 | 登录 B 站 → Cookies → `SESSDATA` | 字幕接口返回空，回退 whisper 转写 |
| **微博** | 整条 Cookie（含 `SUB`） | 登录微博 → 复制 `Cookie` | 只抓到登录引导页 |
| **小红书** | 整条 Cookie（含 `web_session`） | 登录小红书 → 复制 `Cookie` | 403 / 空内容 |

## 不需要登录的

微信公众号、B 站视频（画面与音频）、YouTube、arXiv / 任意 PDF、少数派、
GitHub、Medium、Substack、阮一峰等技术博客，直接抓。

## 说明

- 凭据只存在你自己的账号下（`User.credentials`），只有你自己的任务会用到
- worker 按任务临时注入环境变量，不写日志、不落磁盘
- Cookie 会过期（一般几周到几个月）：抓取开始报 403 时，重新复制一次即可
- 设置页每个站点会显示「已配置 / 未配置」，输入框留空保存 = 清除该站凭据

## 已知仍抓不到的情况

| 情况 | 原因 |
| --- | --- |
| 需要前端渲染的 SPA | worker 不带浏览器，抽不到正文 |
| 付费墙文章 | 需要该站会员 Cookie，且通常有反爬 |
| 抖音 / TikTok 视频 | 需要签名参数，目前只支持 B 站 / YouTube 转写 |
| 小红书笔记 | 除 Cookie 外还有风控签名，成功率不稳 |

## 怎么获取（逐步）

1. **在电脑浏览器登录**对应站点（iPad 没有开发者工具；电脑复制后可用「通用剪贴板」粘贴到 iPad）
2. 打开开发者工具：Chrome / Edge 按 `F12`；Safari 先「设置 → 高级 → 显示网页开发者功能」，再 `⌥⌘I`
3. 按下面的位置复制：

| 站点 | 位置 | 复制什么 |
| --- | --- | --- |
| 知乎 | Network → 任意请求 → Request Headers | `Cookie` 整行（关键 `z_c0`） |
| B 站 | Application → Cookies → `bilibili.com` | `SESSDATA` 的 Value |
| 微博 | Network → 任意请求 → Request Headers | `Cookie` 整行（关键 `SUB`） |
| 小红书 | Application → Cookies | `web_session`（连带 `a1`）或整行 Cookie |

4. 回到本站「设置 → 站点登录态」粘贴 → 保存凭据；状态会变成「已配置」
5. 撤销：把输入框清空再保存即可

> 提示：Cookie 等同登录态，不要发给别人；一般几周到几个月过期，抓取开始报 403 时重新复制一次。
